### 👋 About Me

I build focused, lightweight tools that solve **one problem well** without bloat. Most of my work centers on bringing modern capabilities to hardware-constrained devices like the **TCL Flip 2**, alongside automation scripts for messaging platforms and desktop environments.

- 🎙️ **Flagship Project:** **[Kaylo](https://github.com/Yitz890/Kaylo)** — a D-pad-native voice assistant powered by the Gemini API
- 📱 **Android & Hardware:** Developing **Kotlin APKs** tailored for non-touch D-pad navigation, plus **ADB / Fastboot / MTK** system workflows
- 🐍 **Automation & Tooling:** Writing lightweight **Python**, **JavaScript**, **Shell**, and **Batch** utilities that are fast to run and hard to break
- 🎮 **Also on the bench:** **[D-Pad-Games](https://github.com/Yitz890/D-Pad-Games)** — a modular, plugin-driven game collection for keypad devices
