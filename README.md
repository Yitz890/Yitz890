## 🚧 Currently building

### Kaylo — a D-pad-first voice assistant
Kaylo is an Android voice assistant powered by the **Gemini API**, designed for remotes, gamepads, and other D-pad devices.

- **No touchscreen required** — press to talk, steer with directional controls
- **Voice-first** — ask questions and get spoken responses
- **Remote-friendly** — built for Android TV boxes, handhelds, and controller setups
- **Status:** Alpha / in progress
